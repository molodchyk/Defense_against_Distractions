ಹೆಚ್ಚಿನ ಫೋಕಸ್ ವಿಸ್ತರಣೆಗಳು ಸಂಪೂರ್ಣ ವೆಬ್‌ಸೈಟ್‌ಗಳನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತವೆ. ಅದು ಉಪಯುಕ್ತವಾಗಿದೆ, ಆದರೆ ಇಂಟರ್ನೆಟ್ ಅದಕ್ಕಿಂತ ಗೊಂದಲಮಯವಾಗಿದೆ. ಅದೇ ವೆಬ್‌ಸೈಟ್ ಒಂದು ಕ್ಷಣದಲ್ಲಿ ಸಹಾಯಕವಾಗಬಹುದು ಮತ್ತು ಇನ್ನೊಂದು ಕ್ಷಣದಲ್ಲಿ ತಬ್ಬಿಬ್ಬುಗೊಳಿಸಬಹುದು. ಹುಡುಕಾಟ ಪುಟ, ಚಾಟ್ ಟೂಲ್, ಫೋರಮ್, ವೀಡಿಯೊ ಸೈಟ್, ಅಥವಾ AI ಸಹಾಯಕ ನೈಜ ಕೆಲಸವನ್ನು ಬೆಂಬಲಿಸಬಹುದು, ಆದರೆ ಇದು ಸುದ್ದಿ, ಆಟಗಳು, ನಾಟಕ, ವೀಡಿಯೊಗಳು ಮತ್ತು ಇತರ ಗಮನ ಬಲೆಗಳಿಗೆ ದ್ವಾರವಾಗಬಹುದು.

ವ್ಯಾಕುಲತೆಗಳ ವಿರುದ್ಧ ರಕ್ಷಣೆಯು ನಿಮಗೆ ಹೆಚ್ಚು ನಿಖರವಾದ ನಿಯಂತ್ರಣವನ್ನು ನೀಡುತ್ತದೆ.

URL ಮೂಲಕ ಮಾತ್ರ ನಿರ್ಬಂಧಿಸುವ ಬದಲು, ನೀವು ವೆಬ್‌ಸೈಟ್ ನಮೂದುಗಳು, ಕೀವರ್ಡ್‌ಗಳು ಅಥವಾ ನುಡಿಗಟ್ಟುಗಳು, ತೂಕದ ಸ್ಕೋರ್‌ಗಳು, ಅನುಮತಿಸಿದ ವೆಬ್‌ಸೈಟ್‌ಗಳು, ವೇಳಾಪಟ್ಟಿಗಳು, Pomodoro ನಿಯಮಗಳು, intent coherence ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು ಐಚ್ಛಿಕ UI cleanup ಇರುವ plans ರಚಿಸಬಹುದು. ಹೊಂದುವ ಪುಟವು ಹೊಂದಿಸಿದ distraction score ಮೀರಿದಾಗ, ವಿಸ್ತರಣೆ ಅದನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ.

ಸ್ಟಡಿ ಸೆಷನ್‌ಗಳು, ವರ್ಕ್ ಬ್ಲಾಕ್‌ಗಳು, ಪರೀಕ್ಷೆಯ ತಯಾರಿ, ಸಂಶೋಧನಾ ಸಮಯ ಅಥವಾ ಯಾವುದೇ ಸನ್ನಿವೇಶವನ್ನು ನೀವು ಬಳಸದೆ ಬ್ರೌಸರ್ ಉಪಯುಕ್ತವಾಗಿರಲು ನೀವು ಇದನ್ನು ಬಳಸಬಹುದು.

ಮುಖ್ಯ ಲಕ್ಷಣಗಳು:

ಕೀವರ್ಡ್‌ಗಳು, ನುಡಿಗಟ್ಟುಗಳು ಮತ್ತು ತೂಕದ ಸ್ಕೋರ್‌ಗಳಿಂದ ಪುಟಗಳನ್ನು ನಿರ್ಬಂಧಿಸಿ.
ವಿಭಿನ್ನ focus contexts ಅನ್ನು plans ನಲ್ಲಿ ಸಂಘಟಿಸಿ.
ಸೆಟಪ್ ಪ್ರಾಯೋಗಿಕವಾಗಿರಲು locked schedules, allowed websites, password protection, export/import, UI modes, Pomodoro, intent coherence ಮತ್ತು UI element hiding ಬಳಸಿ.

ಬ್ರೌಸರ್ ಟಿಪ್ಪಣಿಗಳು:
ಬ್ರೌಸರ್ incognito ಮತ್ತು file URL access ಅನ್ನು ನಿಯಂತ್ರಿಸುತ್ತದೆ. ನೀವು ಅಲ್ಲಿ ವಿಸ್ತರಣೆಯನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ಅನುಮತಿಸಿದಾಗ ಮಾತ್ರ DaD ಆ ಪುಟಗಳಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

ಆವೃತ್ತಿ 1.6.1 ರಲ್ಲಿ ಹೊಸದೇನಿದೆ:
Pomodoro ಈಗ idle ಮತ್ತು locked ಸಮಯವನ್ನು ಅಗತ್ಯ ವಿಶ್ರಾಂತಿಯ ಭಾಗವಾಗಿ ಲೆಕ್ಕಿಸುತ್ತದೆ.
ಪಾಪ್‌ಅಪ್ ಮತ್ತು ಪ್ಲಾನ್ Pomodoro ಪುಟವು ಈಗ runtime diagnostics ಅನ್ನು ಹೆಚ್ಚು ಸ್ಪಷ್ಟವಾಗಿ ತೋರಿಸುತ್ತದೆ.
Strict-break blocking ಈಗ block ಮುಗಿದ ನಂತರ media ಮತ್ತು tab mute ಸ್ಥಿತಿಯನ್ನು ಮರುಸ್ಥಾಪಿಸುತ್ತದೆ.
Blocked-page diagnostics ಈಗ media suspension ಮತ್ತು extension-owned tab mute state ಅನ್ನು ತೋರಿಸುತ್ತದೆ.
