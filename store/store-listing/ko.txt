대부분의 집중 도구 확장 프로그램은 웹사이트 전체를 차단합니다. 도움이 되지만, 인터넷은 그보다 더 복잡합니다. 같은 사이트도 어떤 순간에는 유용하고 다른 순간에는 방해가 될 수 있습니다. 검색 페이지, 채팅 도구, 포럼, 동영상 사이트, AI 도우미는 실제 작업을 도울 수 있지만 뉴스, 게임, 논란, 동영상 등 주의를 빼앗는 길이 되기도 합니다.

Defense Against Distractions는 더 정밀한 제어를 제공합니다.

URL만으로 차단하는 대신, 웹사이트 항목, 키워드나 문구, 가중 점수, 허용된 웹사이트, 일정, Pomodoro 규칙, intent coherence 설정, 선택적 UI 정리를 포함한 plan을 만들 수 있습니다. 일치하는 페이지가 설정된 distraction score를 넘으면 확장 프로그램이 해당 페이지를 차단합니다.

학습 세션, 작업 시간, 시험 준비, 조사 시간 또는 브라우저가 유용하게 남아 있어야 하는 모든 상황에서 사용할 수 있습니다.

주요 기능:

키워드, 문구, 가중 점수로 페이지 차단.
서로 다른 집중 맥락을 plan으로 정리.
잠긴 일정, 허용된 웹사이트, 비밀번호 보호, export/import, UI modes, Pomodoro, intent coherence, UI 요소 숨기기를 사용해 설정을 실용적으로 유지.

브라우저 참고 사항:
브라우저가 incognito 및 file URL 접근을 제어합니다. DaD는 해당 페이지에서 확장 프로그램을 명시적으로 허용한 경우에만 작동합니다.

버전 1.6.1의 새로운 기능:
Pomodoro가 이제 유휴 시간과 잠금 시간을 필요한 휴식 시간으로 계산합니다.
팝업과 플랜 Pomodoro 페이지가 이제 더 명확한 런타임 진단을 보여줍니다.
엄격한 휴식 차단은 차단이 끝난 뒤 미디어와 탭 음소거 상태를 복원합니다.
차단된 페이지 진단이 이제 미디어 일시 중지와 확장 프로그램이 설정한 탭 음소거 상태를 표시합니다.
