ფოკუსის გაფართოებების უმეტესობა ბლოკავს მთელ ვებსაიტებს. ეს სასარგებლოა, მაგრამ ინტერნეტი ამაზე უფრო ბინძურია. ერთი და იგივე ვებსაიტი ერთ მომენტში შეიძლება იყოს გამოსადეგი და მეორეში ყურადღების გადატანა. საძიებო გვერდს, ჩეთის ხელსაწყოს, ფორუმს, ვიდეო საიტს ან ხელოვნური ინტელექტის ასისტენტს შეუძლია რეალური მუშაობის მხარდაჭერა, მაგრამ ის ასევე შეიძლება გახდეს ახალი ამბების, თამაშების, დრამის, ვიდეოების და სხვა ყურადღების ხაფანგების კარი.

ყურადღების გაფანტვისგან დაცვა გაძლევს უფრო ზუსტ კონტროლს.

მხოლოდ URL-ით დაბლოკვის ნაცვლად, შეგიძლიათ შექმნათ გეგმები ვებსაიტის ჩანაწერებით, საკვანძო სიტყვებით ან ფრაზებით, წონიანი ქულებით, დაშვებული ვებსაიტებით, განრიგებით, Pomodoro წესებით, intent coherence პარამეტრებით და არჩევითი UI გაწმენდით. როდესაც შესაბამისი გვერდი გადააჭარბებს დაყენებულ გაფანტვის ქულას, გაფართოება მას ბლოკავს.

თქვენ შეგიძლიათ გამოიყენოთ ის სასწავლო სესიების, სამუშაო ბლოკების, გამოცდების მომზადების, კვლევის დროის ან ნებისმიერი სიტუაციის დასაცავად, როდესაც გსურთ, რომ ბრაუზერი იყოს სასარგებლო, შემოვლითი გზა არ გახდეს.

ძირითადი მახასიათებლები:

დაბლოკეთ გვერდები საკვანძო სიტყვების, ფრაზებისა და წონიანი ქულების მიხედვით.
სხვადასხვა ფოკუსის კონტექსტი გეგმებში დაალაგეთ.
გამოიყენეთ ჩაკეტილი განრიგები, დაშვებული ვებსაიტები, პაროლის დაცვა, ექსპორტი/იმპორტი, UI რეჟიმები, Pomodoro, intent coherence და UI ელემენტების დამალვა, რათა კონფიგურაცია პრაქტიკული დარჩეს.

ბრაუზერის შენიშვნები:
ბრაუზერი აკონტროლებს incognito და file URL წვდომას. DaD ამ გვერდებზე მუშაობს მხოლოდ მაშინ, როცა გაფართოებას იქ მკაფიოდ აძლევთ ნებართვას.

რა არის ახალი ვერსია 1.6.1:
Pomodoro ახლა უსაქმურ და ჩაკეტილ დროს საჭირო დასვენებაში ითვლის.
