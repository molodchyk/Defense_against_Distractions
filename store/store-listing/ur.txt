زیادہ تر فوکس ایکسٹینشن پوری ویب سائٹس کو بلاک کر دیتے ہیں۔ یہ مفید ہے، لیکن انٹرنیٹ اس سے زیادہ گندا ہے۔ وہی ویب سائٹ ایک لمحے میں مددگار اور دوسرے لمحے پریشان کر سکتی ہے۔ تلاش کا صفحہ، چیٹ ٹول، فورم، ویڈیو سائٹ، یا AI اسسٹنٹ حقیقی کام کی حمایت کر سکتا ہے، لیکن یہ خبروں، گیمز، ڈراموں، ویڈیوز اور دیگر توجہ کے جال کا دروازہ بھی بن سکتا ہے۔

خلفشار کے خلاف دفاع آپ کو زیادہ درست کنٹرول فراہم کرتا ہے۔

صرف URL کے ذریعے بلاک کرنے کے بجائے، آپ website entries، keywords یا phrases، weighted scores، allowed websites، schedules، Pomodoro rules، intent coherence settings اور اختیاری UI cleanup والے plans بنا سکتے ہیں۔ جب کوئی matching page configured distraction score سے آگے بڑھتا ہے تو extension اسے بلاک کر دیتی ہے۔

آپ اسے مطالعہ کے سیشنز، کام کے بلاکس، امتحان کی تیاری، تحقیق کے وقت، یا ایسی کسی بھی صورت حال کی حفاظت کے لیے استعمال کر سکتے ہیں جہاں آپ چاہتے ہیں کہ براؤزر بغیر کسی چکر کا شکار بنے مفید رہے۔

اہم خصوصیات:

keywords، phrases اور weighted scores کے ذریعے pages کو بلاک کریں۔
مختلف focus contexts کو plans میں منظم کریں۔
setup کو عملی رکھنے کے لیے locked schedules، allowed websites، password protection، export/import، UI modes، Pomodoro، intent coherence اور UI element hiding استعمال کریں۔

براؤزر نوٹس:
براؤزر incognito اور file URL access کو کنٹرول کرتا ہے۔ DaD ان pages پر صرف اس وقت کام کرتا ہے جب آپ وہاں extension کو واضح طور پر اجازت دیتے ہیں۔
