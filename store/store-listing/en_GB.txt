Most focus extensions block whole websites. That is useful, but the internet is messier than that. The same website can be helpful in one moment and distracting in another. A search page, chat tool, forum, video site, or AI assistant can support real work, but it can also become a doorway into news, games, drama, videos, and other attention traps.

Defense Against Distractions gives you more precise control.

Rules and page checks are processed locally in the browser; core blocking does not need a remote server.

Instead of only blocking by URL, you can create plans with website entries, keywords or phrases, weighted scores, allowed websites, schedules, Pomodoro rules, intent-coherence settings, and optional UI cleanup. When a matching page crosses the configured distraction score, the extension blocks it.

You can use it to protect study sessions, work blocks, exam preparation, research time, or any situation where you want the browser to stay useful without becoming a detour.

Main features:

Block pages by keywords, phrases, and weighted scores.
Organize different focus contexts into plans.
Use locked schedules, allowed websites, password protection, export/import, UI modes, Pomodoro, intent coherence, and UI element hiding to keep the setup practical.

Browser notes:
The browser controls incognito and file URL access. DaD only works on those pages when you explicitly allow the extension there.

What is new in version 1.6.1:
Pomodoro now counts idle and locked time towards required rest.
The popup and plan Pomodoro page now show clearer runtime diagnostics.
Strict-break blocking now restores media and tab mute state after the block ends.
Blocked-page diagnostics now show media suspension and extension-owned tab mute state.
