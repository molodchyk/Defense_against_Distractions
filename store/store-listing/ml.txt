മിക്ക ഫോക്കസ് എക്സ്റ്റൻഷനുകളും മുഴുവൻ വെബ്‌സൈറ്റുകളെയും തടയുന്നു. അത് ഉപയോഗപ്രദമാണ്, പക്ഷേ ഇൻ്റർനെറ്റ് അതിനേക്കാൾ കുഴപ്പമാണ്. ഒരേ വെബ്സൈറ്റ് ഒരു നിമിഷത്തിൽ സഹായകരവും മറ്റൊരു നിമിഷത്തിൽ ശ്രദ്ധ തിരിക്കുന്നതും ആയിരിക്കും. ഒരു തിരയൽ പേജ്, ചാറ്റ് ടൂൾ, ഫോറം, വീഡിയോ സൈറ്റ് അല്ലെങ്കിൽ AI അസിസ്റ്റൻ്റിന് യഥാർത്ഥ ജോലിയെ പിന്തുണയ്ക്കാൻ കഴിയും, എന്നാൽ ഇത് വാർത്തകൾ, ഗെയിമുകൾ, നാടകം, വീഡിയോകൾ, മറ്റ് ശ്രദ്ധാകേന്ദ്രങ്ങൾ എന്നിവയിലേക്കുള്ള ഒരു വാതിലായി മാറും.

ശ്രദ്ധ വ്യതിചലനങ്ങൾക്കെതിരായ പ്രതിരോധം നിങ്ങൾക്ക് കൂടുതൽ കൃത്യമായ നിയന്ത്രണം നൽകുന്നു.

URL വഴി മാത്രം തടയുന്നതിന് പകരം, വെബ്സൈറ്റ് എൻട്രികൾ, കീവേഡുകൾ അല്ലെങ്കിൽ വാക്യങ്ങൾ, weighted scores, allowed websites, schedules, Pomodoro rules, intent coherence settings, ഐച്ഛിക UI cleanup എന്നിവയുള്ള plans നിങ്ങൾക്ക് സൃഷ്ടിക്കാം. പൊരുത്തപ്പെടുന്ന ഒരു പേജ് സജ്ജമാക്കിയ distraction score കടന്നാൽ extension അത് തടയും.

പഠന സെഷനുകൾ, വർക്ക് ബ്ലോക്കുകൾ, പരീക്ഷാ തയ്യാറെടുപ്പുകൾ, ഗവേഷണ സമയം അല്ലെങ്കിൽ ബ്രൗസർ ഒരു വഴിമാറി പോകാതെ ഉപയോഗപ്രദമായി തുടരാൻ നിങ്ങൾ ആഗ്രഹിക്കുന്ന ഏത് സാഹചര്യത്തിലും പരിരക്ഷിക്കാൻ നിങ്ങൾക്ക് ഇത് ഉപയോഗിക്കാം.

പ്രധാന സവിശേഷതകൾ:

കീവേഡുകൾ, വാക്യങ്ങൾ, weighted scores എന്നിവ പ്രകാരം പേജുകൾ തടയുക.
വ്യത്യസ്ത focus contexts plans ആയി ക്രമീകരിക്കുക.
സജ്ജീകരണം പ്രായോഗികമായി നിലനിർത്താൻ locked schedules, allowed websites, password protection, export/import, UI modes, Pomodoro, intent coherence, UI element hiding എന്നിവ ഉപയോഗിക്കുക.

ബ്രൗസർ കുറിപ്പുകൾ:
ബ്രൗസർ incognito, file URL access എന്നിവ നിയന്ത്രിക്കുന്നു. നിങ്ങൾ അവിടെ extension വ്യക്തമായി അനുവദിച്ചാൽ മാത്രമേ DaD ആ പേജുകളിൽ പ്രവർത്തിക്കൂ.

പതിപ്പ് 1.6.1-ൽ എന്താണ് പുതിയത്:
Pomodoro ഇപ്പോൾ idle സമയവും locked സമയവും ആവശ്യമായ വിശ്രമമായി എണ്ണുന്നു.
പോപ്പപ്പും പ്ലാൻ Pomodoro പേജും ഇപ്പോൾ runtime diagnostics കൂടുതൽ വ്യക്തമായി കാണിക്കുന്നു.
Strict-break blocking ഇപ്പോൾ block അവസാനിച്ച ശേഷം mediaയും tab mute നിലയും പുനഃസ്ഥാപിക്കുന്നു.
Blocked-page diagnostics ഇപ്പോൾ media suspensionയും extension-owned tab mute stateയും കാണിക്കുന്നു.
