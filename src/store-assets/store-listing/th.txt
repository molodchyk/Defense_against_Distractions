Defense Against Distractions ช่วยให้คุณมีสมาธิเมื่อการบล็อกเว็บไซต์แบบธรรมดาไม่เพียงพอ

ส่วนขยายเพื่อโฟกัสส่วนใหญ่มักบล็อกทั้งเว็บไซต์ วิธีนี้มีประโยชน์ แต่อินเทอร์เน็ตซับซ้อนกว่านั้น เว็บไซต์เดียวกันอาจมีประโยชน์ในช่วงหนึ่ง และกลายเป็นสิ่งรบกวนในอีกช่วงหนึ่ง หน้าเว็บค้นหา เครื่องมือแชท ฟอรัม เว็บไซต์วิดีโอ หรือผู้ช่วย AI สามารถช่วยงานจริงได้ แต่ก็อาจกลายเป็นทางเข้าสู่ข่าว เกม ดราม่า วิดีโอ และกับดักความสนใจอื่น ๆ ได้เช่นกัน

Defense Against Distractions ให้คุณควบคุมได้ละเอียดขึ้น

แทนที่จะบล็อกตาม URL เท่านั้น คุณสามารถบล็อกหน้าตามคำและวลีที่ปรากฏบนหน้านั้นได้ สร้างกลุ่มเว็บไซต์ เพิ่มคีย์เวิร์ดหรือวลี กำหนดคะแนน แล้วให้ส่วนขยายบล็อกหน้าเมื่อคะแนนความรบกวนเกินค่าที่คุณตั้งไว้

คุณสามารถใช้เพื่อปกป้องช่วงเรียน ช่วงทำงาน การเตรียมสอบ เวลาค้นคว้า หรือสถานการณ์ใด ๆ ที่ต้องการให้เบราว์เซอร์ยังมีประโยชน์โดยไม่กลายเป็นทางออกนอกเรื่อง

คุณสมบัติหลัก:

บล็อกหน้าตามคีย์เวิร์ด วลี และคะแนนแบบถ่วงน้ำหนัก
จัดระเบียบกฎโฟกัสต่าง ๆ เป็นกลุ่มเว็บไซต์และคีย์เวิร์ด
ใช้ตารางเวลาที่ล็อกไว้ whitelist การป้องกันด้วยรหัสผ่าน export/import โหมด UI และการซ่อนองค์ประกอบ UI เพื่อให้การตั้งค่าใช้งานได้จริง

มีอะไรใหม่ในเวอร์ชัน 1.5:

โหมด UI สว่าง มืด และตามระบบ
ตัวเลือกองค์ประกอบ UI จาก popup เพื่อซ่อนปุ่มหรือส่วนควบคุมที่รบกวนบนหน้าเว็บ
overlay หน้าบล็อกที่ปรับปรุงแล้ว พร้อมหยุดหรือปิดเสียงสื่อ และ diagnostics ที่เลือกคัดลอกได้
อัปเดต store assets การแพ็กเกจ การตรวจสอบ release และโครงสร้างโปรเจกต์
