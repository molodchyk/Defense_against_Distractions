Defense Against Distractions: Instruction Guide

Introduction

Defense Against Distractions lets you create local protection plans that block pages, guide Pomodoro timing, detect possible intent drift, and clean up distracting page UI.

A plan combines page entries, allowed websites, schedules, Pomodoro settings, intent-coherence settings, and optional UI cleanup rules. Turn a plan on when you want that protection available.

The extension checks configured pages locally in the browser. It does not send page text, browsing diagnostics, or settings to a remote server.

Start with one plan, add the pages and words that matter, then make the plan stricter with schedules or Pomodoro when you need stronger defense.

How to Use the Extension

First Step: Create a Plan

Enter a plan name and press Add Plan. Open the plan to configure entries, schedules, Pomodoro, intent coherence, allowed websites, and UI cleanup assignments.

The default plan is a safe starting point. You can keep it, rename it, or create additional plans for different contexts.

Entries and Websites

A plan entry has websites and keywords. Add the websites where the keywords should be scanned, one host per line, such as example.com or docs.example.com.

Keywords

Add keywords or phrases to the same entry. The extension scans matching pages locally and blocks the page when the entry score reaches 1000.

There are 3 formats for the keywords:

  • Keyword format 1: Enter a word or phrase. If the keyword contains a comma, put a backslash before the comma. A plain keyword blocks as soon as it is detected.

    Examples: "video games", "news".

  • Keyword format 2: Add a number after a comma. The page score starts at 0 and increases by that amount each time the keyword is found. At 1000, the page is blocked.

    Example: "news, 50"

    Use this when a word should matter, but only after repeated or combined signals.

  • Keyword format 3: Use * or + with a number when you want a keyword to multiply or add to the current page score in a more explicit way.

    Example: "news, *, 10"

    Use this for stronger signals that should become decisive only in a specific context.

Pomodoro

A plan can run Pomodoro work and rest timing. Strict breaks can block or quiet pages during rest so the break is protected.

Pomodoro Timing

Set work minutes, short breaks, long breaks, and how many work sessions happen before a long break. During an active protected schedule, enabling Pomodoro or making it stricter is allowed; relaxing it is blocked.

Locked Schedules

A protected schedule is meant to resist hot-state weakening while the scheduled window is active.

Open a plan, choose Schedule, and add one or more scheduled time blocks. Each block can choose days, start time, end time, and whether it is protected.

A protected active schedule can be made stricter but not more relaxed. For example, you can add entries, raise keyword scores, enable stricter Pomodoro behavior, or add UI cleanup rules, but you cannot remove active protection.

Delete removes a schedule only when doing so does not relax an active protected window.

During an active protected schedule, relaxed changes are refused:

  1. You cannot disable the active plan.
  2. You cannot remove existing plan entries or reduce the websites they protect.
  3. You cannot remove existing keywords or reduce their weights.
  4. New or changed keywords must stay inside the strict allowed scoring ranges.
  5. You cannot disable Pomodoro, turn off strict breaks, or make Pomodoro easier to bypass.
  6. You can enable Pomodoro or make its timing stricter when that increases protection.
  7. Active schedules cannot be deleted.
  8. You cannot remove active days or shrink an active protected schedule window.
  9. You cannot add allowed websites to bypass a protected plan.
  10. You cannot delete password protection during an active protected schedule.

Allowed Websites

Allowed websites are plan-owned exceptions. Add them when a site should remain usable while a plan is active; the plan will not scan or block those allowed hosts.

Password Management

Password protection can require a password before opening the options page. Use it when you want an extra barrier around changing protection settings.
