# Evidence Card

## Source

Citation: Leroy, S., & Glomb, T. M. (2018). Tasks Interrupted: How Anticipating Time Pressure on Resumption of an Interrupted Task Causes Attention Residue and Low Performance on Interrupting Tasks and How a "Ready-to-Resume" Plan Mitigates the Effects. Organization Science, 29(3), 380-397.

Link: https://pubsonline.informs.org/doi/10.1287/orsc.2017.1184

DOI: https://doi.org/10.1287/orsc.2017.1184

## Source Type

- primary study
- experiments
- organizational psychology

## Research Context

The paper examines interruptions and attention residue, especially when people expect to resume interrupted work under time pressure. It tests a ready-to-resume intervention: briefly reflecting on and planning the return to the interrupted task.

## Main Finding

When people anticipated time pressure on resumption, they had more difficulty focusing on the interrupting task. A ready-to-resume plan reduced attention residue and protected performance across four studies.

## Empirical Detail

- Design: four studies.
- Context: interruption of a primary task and anticipated pressure when resuming it.
- Main pattern: anticipated time pressure on resumption increased attention residue and reduced performance on the interrupting task.
- Intervention: a ready-to-resume plan, where participants briefly reflected on the interrupted task and planned how to return.
- Result direction: the ready-to-resume plan mitigated attention residue and performance costs.

## Non-Obvious Mechanism

The useful move is not only returning immediately. A short resumption plan can let the user cognitively set down the unfinished task so they can engage the new one more cleanly.

## Limitations

This is not a browser-extension study. The intervention is a human planning note, not an automated Return button. It does not prove that DaD should block a drift page.

## Evidence Grade

strong for ready-to-resume planning in interruption contexts; moderate for DaD application.

## Relevance To DaD

DaD's Return action is effectively a ready-to-resume affordance: it tells the user where they were last coherent and gives an immediate path back. Show graph can make the resumption point visible. Continue with a reason can serve as a small planning step when the user chooses not to return.

## Design Consequence

DaD should strengthen the "last coherent" and "first drift" surfaces. They are not merely diagnostics; they can help the user form a return plan.

Continue should remain possible in non-hard interventions, but requiring a short reason is consistent with a lightweight planning step rather than a punishment.

## What Changes

Continue and Isolate should not be mere dismissals. They should either restore a resumption cue for the old chain or create a clean new baseline for the current one.

## Notes

This is the strongest source for Return and for the general idea that recovery affordances should be concrete, not abstract.
