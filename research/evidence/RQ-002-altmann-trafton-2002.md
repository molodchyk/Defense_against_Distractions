# Evidence Card

## Source

Citation: Altmann, E. M., & Trafton, J. G. (2002). Memory for Goals: An Activation-Based Model. Cognitive Science, 26(1), 39-83.

Link: https://onlinelibrary.wiley.com/doi/abs/10.1207/s15516709cog2601_2

DOI: https://doi.org/10.1207/s15516709cog2601_2

## Source Type

- theory/model paper
- cognitive science

## Research Context

The paper models goal-directed cognition using memory activation and associative priming. It is relevant to interruption and resumption because goals must remain retrievable after a task is suspended.

## Main Finding

Goals can be modeled as memory representations whose activation changes over time and with cues. Interruptions matter because the suspended goal must later be retrieved and resumed.

## Limitations

This is a cognitive model, not direct evidence that a browser graph improves real-world browsing outcomes. It mostly concerns structured tasks and goal retrieval.

## Evidence Grade

moderate.

## Relevance To DaD

DaD's last coherent page and graph act as external retrieval cues for the suspended browsing objective. Return gives a concrete cue and route back to the prior goal context.
