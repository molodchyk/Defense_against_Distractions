# Claim Traceability

This document maps visible release and store-review claims to the evidence that proves them. Keep it in sync when README, store listing text, privacy copy, manifest permissions, package output, or release gates change.

| Claim | Visible surfaces | Evidence and gate |
| --- | --- | --- |
| Defense Against Distractions is local-first. | `README.md`, `PRIVACY.md`, `store/store-listing/*.txt`, `docs/chrome-web-store-privacy-form.md` | Runtime behavior is implemented without a remote backend. `PRIVACY.md` states local Chrome extension storage. `scripts/check-package-output.mjs` rejects unexpected remote network access in the generated runtime package. |
| The runtime extension package does not use analytics, ads, tracking pixels, telemetry, or developer analytics dashboards. | `README.md`, `PRIVACY.md`, `docs/reviewer-notes.md`, `docs/chrome-web-store-privacy-form.md` | `scripts/check-package-output.mjs` rejects recognized analytics, tracking, and telemetry SDK signatures. `PRIVACY.md` separates local user-facing diagnostics from developer analytics. |
| The runtime extension package does not use remote JavaScript, WebAssembly, or other remote executable code. | `PRIVACY.md`, `docs/chrome-web-store-privacy-form.md`, `docs/release-readiness.md` | `scripts/check-package-output.mjs` rejects remote executable script tags, remote worker scripts, remote WebAssembly streaming loads, and remote executable URL patterns. |
| The runtime extension package does not make remote network requests. | `README.md`, `PRIVACY.md`, `docs/release-readiness.md`, `store/store-listing/*.txt` | `scripts/check-package-output.mjs` rejects remote `fetch`, beacon, WebSocket, EventSource, remote passive HTML requests, remote CSS URLs, and similar runtime network patterns unless explicitly allowed. |
| Manifest permissions are minimal and explainable. | `PRIVACY.md`, `docs/permission-audit.md`, `docs/chrome-web-store-privacy-form.md` | `manifest.json` is checked against the audited permission set: `storage`, `alarms`, `downloads`, `activeTab`, `idle`, and `webNavigation`. `scripts/check-browser-extension-playbook.mjs` rejects unaudited manifest keys and broad optional host/permission surfaces. |
| Broad host access is limited to audited content-script and web-accessible-resource surfaces. | `PRIVACY.md`, `docs/permission-audit.md`, `docs/reviewer-notes.md` | `scripts/check-browser-extension-playbook.mjs` verifies content script and web-accessible-resource `<all_urls>` usage and rejects `host_permissions`, `optional_host_permissions`, and `optional_permissions`. |
| Store listing files are direct Chrome Web Store detailed-description bodies. | `store/store-listing/*.txt`, `docs/storepilot-automation.md` | `scripts/check-browser-extension-playbook.mjs` verifies one `.txt` listing per locale, no Markdown, no field labels, no leading extension name, no stale version numbers, and the canonical GPL/source footer. |
| Store media does not expose personal accounts, private conversations, real rules, real domains, or other user-specific configuration, and screenshots match current store-copy themes. | `store/screenshots/`, `store/promo/`, `docs/store-media-review.md` | `docs/store-media-review.md` records reviewed hashes, privacy boundaries, and the screenshot-to-store-copy consistency map. `scripts/check-browser-extension-playbook.mjs` verifies reviewed hashes, required image dimensions, and consistency-map coverage. |
| Runtime ZIP excludes source-only files. | `docs/release-readiness.md`, `docs/reviewer-notes.md` | `scripts/package-extension.ps1`, `scripts/verify-package-output.ps1`, and `scripts/verify-release.ps1` verify the extension archive excludes docs, research, tests, scripts, screenshots, promo images, store listing text, and source-only icon files. |
| Source ZIP contains reviewer and release evidence. | `docs/release-readiness.md`, `docs/release-verification-record.md` | `scripts/verify-release.ps1` requires README, privacy policy, license, changelog, docs, scripts, tests, source, store assets, StorePilot documents, media review, and this claim traceability file in the source archive. |
| The extension is open source under GPL-3.0-only. | `README.md`, `package.json`, `LICENSE`, `store/store-listing/*.txt` | `LICENSE` contains GPLv3 text, `package.json` uses `GPL-3.0-only`, and store listing files end with the canonical GPL/source footer. |
| Current static release gates passed, but browser-load remains pending until isolated verification. | `docs/release-readiness.md`, `docs/release-verification-record.md`, `docs/browser-extension-playbook-compliance.md`, `docs/browser-extension-playbook-requirements.md` | `npm run verify:release` covers static repository, package, archive, locale, and source checks. `npm run verify:browser-load` remains a required isolated target-browser check and is not part of automated static gates. |
